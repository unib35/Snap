# TDD Status

현재 TDD 진행 상황을 확인합니다.

## 실행 단계

1. plan.md 파일 읽기

2. 진행 상황 분석
   - 완료된 테스트 수 (`- [x]`)
   - 남은 테스트 수 (`- [ ]`)
   - 진행률 계산

3. 결과 출력
   ```
   📊 TDD 진행 상황
   ✅ 완료: N개 | ⏳ 남음: M개 | 📈 진행률: X%

   🎯 다음 테스트: [테스트명]
   📍 위치: [파일 경로]
   ```

4. 다음 단계 제안
   - `/tdd-next`: 다음 테스트 상세 확인
   - `/tdd-go`: 다음 테스트 구현

## 주의사항
- plan.md가 없으면 `/tdd-plan` 실행 안내
