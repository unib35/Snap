# TDD Commit

TDD 원칙에 맞는 커밋을 수행합니다.

## 입력 (선택)
$ARGUMENTS: 커밋 메시지 (없으면 자동 생성)

## 실행 단계

1. 변경 사항 확인
   ```bash
   git status
   git diff --staged
   ```

2. 검증 수행 (자동)
   - 빌드 확인
   - 테스트 통과 확인

3. 커밋 메시지 생성
   - docs/git/commit.md 컨벤션 준수
   - 적절한 Type 선택
   - 관련 이슈 번호 연결

4. 커밋 실행
   ```bash
   git add -A
   git commit -m "[Type]: 메시지

   - 세부 내용

   Close #이슈번호"
   ```

## 커밋 타입

| Type         | 용도                    |
| ------------ | ----------------------- |
| `[Feat]`     | 새 기능 (행위적 변경)   |
| `[Fix]`      | 버그 수정               |
| `[Refactor]` | 리팩토링 (구조적 변경)  |
| `[Test]`     | 테스트 추가/수정        |
| `[Setting]`  | 프로젝트 설정           |
| `[Docs]`     | 문서 작업               |

## 주의사항
- 구조적 변경과 행위적 변경 분리
- 테스트 통과 상태에서만 커밋
- 이슈 번호 연결 권장
